# Developer-Machine Cleanup Targets

Created: 2026-09-15 10:31:50 IST  
Related task: `KUN-082`  
Status: research and future-work candidates; see [`context.md`](context.md) for implemented CLI behavior.

The categories group storage by its owning tool or workflow. This makes future `kundol optimise storage` and `kundol optimise projects <workdir>` plans explainable and supports tool-native removal where available. The safety stance is a proposal, not permission to delete every path in a category. A plan should show the exact target, physical bytes likely to be reclaimed, rebuild or redownload cost, active-use evidence, and the classification reason; apply must recheck the live target. User data, configuration, secrets, project source, databases, and releases remain protected or review-only.
